# План маршрута

Отдельная вкладка в «Тренировках», прямая ссылка `#path-planner`. Не меняет существующие «Маршрут» и «Скан конём».

## Правила и интерфейс

До запуска можно рассмотреть поле без ограничения времени. Нажать «Начать маршрут», затем выбирать клетки касанием, мышью или клавиатурой. Поля 5×5/6×6; соседние клетки только по горизонтали/вертикали либо стандартный ход коня. Конь перепрыгивает препятствия, но не может на них приземляться. Цель — звезда; промежуточные точки 1 и 2 нужно пройти по порядку. Неверный клик не перемещает фигуру и не штрафуется: это упражнение на планирование.

Можно включить изменение препятствий после первого хода. Изменившиеся клетки выделяются янтарным контуром. Для любого допустимого первого шага заранее проверена возможность закончить маршрут. «Назад» восстанавливает и положение, и прогресс промежуточных целей, и предыдущую карту; повтор того же первого хода вызывает то же изменение. «Сбросить» возвращает это же поле в подготовку; «Следующее поле» создает новое.

Подсказка обводит следующий шаг одного из кратчайших маршрутов и явно учитывается в результате. Завершение сравнивает итоговый путь с кратчайшим; в меняющемся поле сравнение выполняется для уже выбранного первого хода и фактически открывшейся карты, а не с заранее неизвестным ребенку вариантом изменения. Результат не оценивает способности ребенка.

Таймер необязателен: без ограничения, 1 или 2 минуты. Начинается после запуска; скрытие вкладки останавливает отсчет. После истечения срока доступны сброс того же поля и новое поле. Отмена хода не возвращает потраченное время. Поле, действия и текущая статистика помещаются в общий рабочий режим без прокрутки.

## Архитектура

- `src/modules/path-planner/logic.ts`: чистые соседи, допустимость хода, прогресс точек, BFS, генерация с внедряемым RNG.
- BFS ищет по состоянию «клетка + число пройденных по порядку точек». Динамическое поле имеет отдельную заранее рассчитанную карту для каждого первого шага; после первого изменения карта стабильна.
- Генератор проверяет путь до изменения и после каждого допустимого первого шага. Для узких коридоров есть безопасный вариант открытия стены; ограниченное число попыток заканчивается проверяемым открытым полем. Случайность не используется во время отмены/повтора.
- `index.ts`: DOM, фазы подготовки/движения/завершения/истечения времени, таймер и локальное сохранение. `styles.css` содержит только локальные классы.
- Переиспользуются оболочка MathLab, общая работа на одном экране и звук. Меню регистрирует независимый маршрут; шахматный движок и прежние упражнения не меняются.
- Ключ `sciencechess-planner:v1:<profile>`: настройки, общее число решенных полей, последние 100 результатов. Повторное решение того же текущего поля не увеличивает число решенных. Прогресс текущего пути не сохраняется при выходе; новое открытие создает поле с сохраненными настройками. При недоступном localStorage механика работает без сохранения.

## Проверки

`npm test`, `npm run build`, `node e2e/path-planner.mjs`, `npm run test:math`.

Проверяются все комбинации размеров, правил, числа точек и изменения препятствий на детерминированных наборах; проходимость каждой первой ветки, легальность маршрутов, кратчайшие известные примеры, порядок точек, отмена, сброс, однократный результат, таймер, фоновая пауза, сохранение и отсутствие хранилища. Browser-тест проходит задачи обычными шагами и конём на 320×568, 390×844, 820×1180, 844×390 и 1440×900. Авторизованный production smoke проверяет прямой маршрут из приложения и возврат в MathLab.

Скриншоты находятся в `screenshots/`. Браузер — Chromium с касаниями; физический iPad/Safari не проверялся.

В той же поставке в простом «Потоке сложения» добавлена независимая настройка «Порядок ответов → Вперемешку». Числа 0–10/20 присутствуют ровно по разу; новая задача меняет перестановку, ошибочная попытка ее сохраняет. Счет и жизни при смене порядка не сбрасываются.
