# Звуки действий

`src/core/move-sound.ts` — общий Web Audio-сервис: деревянный стук хода, более тихий щелчок выбора, чуть более низкий отклик отправки ответа. Без скачивания аудиофайлов. Общий выключатель «Звуки действий» сохраняет старый ключ `chesslab.move-sound`, поэтому прежнее отключение звука продолжает действовать.

Семантические кнопки, ссылки, раскрывающиеся блоки, select, checkbox/radio/number и range обслуживаются один раз на документе. Ввод текста, автоматические изменения, наведение и программные клики не озвучиваются. Доски с собственными pointer-обработчиками вызывают сервис после проверки допустимости действия; звук pointerdown откладывается до отпускания и отменяется при свайпе. Дубли одного жеста объединяются, активные звуки не накладываются. Движение ползунка ограничено по частоте звуков.

Время реакции фиксируется до генерации звука; правила, результаты и расписание заданий не меняются. Сервис инициализируется в точке входа, поэтому работает и при прямом открытии MathLab. При отсутствии AudioContext приложение продолжает работу без звука.

Проверки: `npm test -- --maxWorkers=2`, `node e2e/move-sound.mjs`, `npm run test:touch`, `npm run test:math`. Для браузерных проверок можно задать `CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`.
