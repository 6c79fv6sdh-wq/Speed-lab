# MathLab 1.0

MathLab добавляет пункт **Математика** в существующий Chesslab. Четыре упражнения используют текущий TypeScript/Vite, DOM-компоненты и hash-навигацию. Новый фреймворк, сервер и регистрация не добавлены. Существующие вход и профиль приложения сохранены.

## Упражнения

- **Мгновенный взгляд** (`#math-glance`): количества 1–4, 1–5, 1–10 и свой диапазон; показ 500–5000 мс; закономерные формы, группы/рамка и случайные малые количества. От пяти точек всегда используется структурированная рамка 5 + остаток. Ответ появляется только после скрытия. Есть цифровые кнопки, Enter, повторный просмотр, отдельное время ответа. При уходе в фон показ останавливается без штрафа, включая начало новой задачи в уже скрытой вкладке.
- **Конструктор числа** (`#math-builder`): исследование чисел 2–10, ползунок с шагом 1, объекты двух групп, перестановка частей. Число и положение ползунка сохраняются. В режиме неизвестной части доступны диапазон, первое/второе/случайное неизвестное; до ответа ползунок и объекты отсутствуют.
- **Друзья десятки** (`#math-friends`): выбор чисел 1–9, включение 0 и 10, три уровня, рамка либо вычисление без неё, смешанное положение неизвестного и равенства, автоматический или ручной переход. После ответа показываются полная пара и рамка.
- **Дострой десятку** (`#math-bridge`): свободный ввод двух чисел и генерация примеров с переходом через десяток. Две коробки по десять ячеек; мышь, Pointer Events для касаний, клавиатура и выбор «шарик → ячейка». Перенос в занятую ячейку или за пределы коробки отклоняется. Отмена и сброс; идентичность и исходные цвета объектов сохраняются. Два наглядных уровня и мысленный режим с тремя ответами (до десятки, остаток, сумма). Демонстрация в мысленном режиме доступна после проверки. До завершения переноса готовое разложение не показывается.

Серии содержат 5, 10, 20 или 30 задач. Исследование не оценивается. В оцениваемой серии засчитывается первая самостоятельная попытка: повтор после разбора не переписывает точность. Подсказки и время ответа хранятся отдельно. Обязательного таймера ответа нет. Можно начать серию заново, завершить её или восстановить настройки.

## Архитектура и файлы

- `src/modules/mathlab/index.ts` — главная страница, общий интерфейс упражнений, настройки и жизненный цикл.
- `logic.ts` — чистые генераторы, разложение числа, дополнение до десяти, расположения точек, неизменяемое состояние шариков и отмена.
- `engine.ts` — учёт единственной первой попытки и формирование результата серии.
- `visuals.ts` — рамки, точки, независимый от математической модели обработчик перетаскивания/выбора.
- `storage.ts` — отдельное версионированное пространство `sciencechess-mathlab:v1:<profile-id>:` с резервом в памяти при недоступном localStorage.
- `styles.css` — стили только внутри `.mathlab`, локальные бирюзовый/янтарный акценты, адаптивность, фокус и reduced motion.
- `src/main.ts` — добавлены маршруты и пункт меню; прямой математический маршрут сохраняется после первоначальной настройки.
- `tests/mathlab-*.test.ts` — математические инварианты, генераторы, состояние серии, таймеры, повторные попытки, хранение и интерфейс.
- `e2e/mathlab*.mjs` — браузерные проверки опубликованной структуры `/lab/`, включая реальные мышиные и сенсорные жесты.

Шахматные модули, их алгоритмы и настройки, IndexedDB и формат шахматных результатов не изменялись. Общие CSS и UI-компоненты не переписывались. Профиль используется только для разделения локальных математических результатов; новые персональные данные не собираются.

## Хранение

Сохраняются настройки каждого тренажёра и последние 200 завершённых серий на текущий профиль: дата, упражнения/задачи, первые ответы, точность, ошибки, время ответа, подсказки и сложность. Для точек — время показа; для друзей десятки — ошибочные пары; для переноса — корректность преобразования и суммы. В случае отказа сохранения появляется сообщение, а занятия продолжаются в памяти вкладки.

Незавершённая серия при выходе не оценивается и не сохраняется как завершённая. Математические данные не включены в шахматный JSON-экспорт и не синхронизируются между устройствами.

## Запуск и проверка

```sh
npm ci
npm run dev
npm test -- --maxWorkers=2
npm run build
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:math
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:e2e
CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium npm run test:touch
```

На системе с установленным Playwright Chromium переменную пути можно не указывать. `test:math` и `test:e2e` временно подставляют тестовый ключ только в `dist`, а затем обязательно восстанавливают production-сборку. Их следует запускать последовательно. Исходный ключ и рабочий доступ не изменяются.

Публикуется содержимое `dist`, как и раньше: в `vladchess-site/lab/` и в `Speed-lab/gh-pages`. Используется `base: './'`, ссылки вида `#math` и `#math-builder` не требуют серверного роутинга.

## Проверенные сценарии и границы

Автоматически проверяются все разложения 2–10 и дополнения 0–10, детерминированная генерация, точное количество и расположение точек, таймеры и фон, защита от двойной записи, перезапуск, повторные попытки. Для переноса проверены 8+5, 7+6, 6+6, 9+8, 9+9, неизменность суммы и идентичности объектов, запрет недопустимых переносов и отмена.

Браузерный прогон использует компьютер 1280×1000, планшет 820×1180, телефон 390×844 и альбомный телефон 844×390. Проходит меню, прямые URL и перезагрузку, все четыре завершённые серии с ошибками, хранение, мышь/нативные касания/выбор ячеек, недопустимый перенос, отмену, отсутствие горизонтальной прокрутки и возврат в шахматное упражнение. Скриншоты находятся в `screenshots/`.

Проверка выполнялась Chromium и его сенсорной эмуляцией; физический iPad/Safari и конкретный screen reader не проверялись. Нет межустройственной синхронизации и серверного хранения — это границы первой версии, а не заявленные функции.
