# Флаги мира

MathLab → «Флаги мира», прямая ссылка `#math-flags` (сохраняет базовый путь сайта).

195 стран: 193 участника ООН, Ватикан и Палестина. Четыре ответа кнопками, ручной переход «Дальше», статистика верных ответов, ошибок и точности. Наборы: все страны, знакомые и редкие. Страны проходят перемешанную колоду без повторений до конца круга; почти одинаковые флаги не предлагаются как конкурирующие ответы.

- `src/modules/mathlab/flag-countries.ts`: названия и коды.
- `flags-logic.ts`: генератор, наборы, проверка сохраненного состояния.
- `flags.ts`, `flags.css`: независимый интерфейс, локальные стили и сохранение.
- `public/flags`: SVG из lipis/flag-icons, лицензия MIT рядом. Швейцария и Ватикан имеют квадратные изображения. Все изображения поставляются с сайтом, внешний сервис не нужен.

Отдельное хранилище `sciencechess-mathlab:v1:<profile>:flags`; текущий вопрос, ответ и счет сохраняются. При недоступном localStorage работает память вкладки. Перезапуск или смена набора начинает счет заново. Ответ блокируется до загрузки изображения; при ошибке загрузки доступен повтор без штрафа. Шахматные правила и результаты не затронуты.

Проверки: `npm test`, `npm run build`, `node e2e/flags.mjs`, `npm run test:math`. Browser-проверка использует Chromium, включая касания и размеры 320×568, 390×844, 820×1180, 844×390, 1440×900; физический iPad/Safari не проверялся. Скриншоты в `screenshots/`.
