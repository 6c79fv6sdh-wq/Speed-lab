# Что висит? — зависшие клики после изменения компоновки

Воспроизведён реальный дефект мышью: появление подписи играющей стороны сдвигает доску вниз без изменения её размера. Chessground хранит прямоугольник доски в memo; Board.refit раньше возвращался при прежнем размере, оставляя старое положение для обработки мыши. Касания чаще работали, потому что touch-адаптер отдельно очищает этот memo перед определением клетки.

Исправление: Board.refit очищает кеш bounds перед проверкой размера. Это также покрывает перемещение видимой области планшета и вход/выход из игрового экрана без ресайза. Алгоритмы задач, ответы, FEN и настройки ввода не изменены.

Проверки:
- tests/board-position-bounds.test.ts: сдвиг на 36/60 px без изменения размера, обновление hit-test и правильное определение a1.
- e2e/hanging-input.mjs: настоящий режим «Что висит?», по 8 решений мышью/касаниями в режимах select/both/drag, включая точную позицию с фото (f5SnT, b2c3) и выход/повторный вход в рабочую область посреди серии. Все 48 ответов должны засчитываться как верные. Набор меняется только в памяти изолированного тестового браузера, исходные задачи не меняются.
- npm test -- --maxWorkers=2; npm run build.

Физический iPad/Safari не проверялся; браузерная проверка использует Chromium, в том числе нативные CDP-касания.
