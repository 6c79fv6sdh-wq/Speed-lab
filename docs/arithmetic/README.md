# Потоки сложения и умножения

MathLab: `#math-addition-flow` и `#math-multiplication-flow`.

| Упражнение | Простой | Сложный |
|---|---|---|
| Сложение | Положительные слагаемые, сумма до 10 или 20 | Два двузначных слагаемых, сумма до 100 |
| Умножение | Таблица 1–10 | Число 11–99 × число 2–9, в обоих порядках |

В обоих упражнениях есть бесконечный поток, выживание до первой ошибки и три жизни. Правильный ответ автоматически сменяет пример через 350 мс. Точность считает правильные ответы с первой попытки; медленный ответ не считается ошибкой.

В простом сложении сохранены привычные кнопки всех чисел. Настройка «Порядок ответов» позволяет выбрать «По порядку» или «Вперемешку». Во втором режиме новый пример получает новую перестановку всех чисел, а при неверном ответе расположение остается прежним. Изменение настройки не сбрасывает счет и жизни; предпочтение хранится отдельно от прежнего формата прогресса. В умножении и сложном сложении показываются четыре крупных различных варианта с единственным правильным. Нативные кнопки доступны мышью, касанием и клавиатурой; редактируемого поля и экранной клавиатуры нет. После завершения попытки кнопки ответов скрываются, чтобы итог помещался и в коротком горизонтальном окне. Статистика остается в верхней панели рабочего режима.

`src/modules/mathlab/addition-flow.ts` содержит общий интерфейс потока и чистые генераторы `AdditionDeck`, `MultiplicationDeck`, `arithmeticChoices`. Колоды конечны, перемешиваются и переиспользуются; перестановка слагаемых или множителей не считается новым примером внутри круга. Два упражнения используют отдельные ключи `sciencechess-mathlab:v1:<profile>:addition-flow` / `multiplication-flow`. Старые сохранения сложения до 10/20 продолжают работать. Смена сложности или игрового режима начинает новую попытку; уход со страницы отменяет переходы. Звук использует существующий общий механизм.

Проверки: `npm test`, `npm run build`, `node e2e/arithmetic-flow.mjs`, `node e2e/addition-sound.mjs`, `npm run test:math`. Новый browser-тест проверяет оба упражнения и уровня на 320×568, 390×844, 820×1180, 844×390 и 1440×900: выбор касанием, верные/неверные ответы, сердца, выживание, сохранение, видимость действий без прокрутки.
