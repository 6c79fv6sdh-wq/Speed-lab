# Крупные координаты и обозначение своей стороны

На настоящих игровых досках добавлена строка «Ты играешь белыми / Ты играешь чёрными» с контрастной фигурой. Сторона задаётся явно параметром `PositionOptions.playerColor` в тактике, премувах, спарринге и дебютах. Она не определяется из ориентации и не меняется во время хода соперника. Пустые доски моторики, просмотр партий и задания без играющей стороны не получают ложную подпись.

Размер координат масштабируется вместе с доской: 14–24 px вместо прежних 9 px. Используются жирное начертание, полная непрозрачность слоя, обводка и цвета выбранной темы доски. Координаты располагаются поверх фигур, не принимают касания и не меняют геометрию клеток. Цифры перенесены в верхние углы своих клеток.

Строка стороны занимает 36 px снаружи клеток; штатный подбор размера доски учитывает это пространство. Менять калибровку, FEN, доступные ходы и ориентацию не требуется.

Проверки: `npm test -- --maxWorkers=2`, `npm run build`, `node e2e/board-clarity.mjs`, `CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium node e2e/touch.mjs`, `node e2e/practice-chess.mjs`. Браузерные проверки Chromium: обе стороны, ход соперника, все 16 координат, квадратность доски, скрытие/очистка подписи, планшетные размеры и основные кнопки без прокрутки.
