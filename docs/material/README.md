# Что ценнее?

Шахматные тренировки → Что ценнее?, маршрут `#material`.

Две группы по 1–3 фигуры, стоимость группы не больше 15. Учебная шкала: пешка 1, конь/слон 3, ладья 5, ферзь 9. Король не участвует. Сравнивается только материал, без оценки позиции. Три отношения выбираются с одинаковой вероятностью; равенство включает разные наборы фигур. Ответ — касание `<`, `=` или `>`, после проверки показаны суммы. Следующее задание только по кнопке. Неправильная первая попытка остается ошибкой после повторения.

Чистая генерация: `src/modules/mathlab/material.ts`. Интерфейс использует имеющийся движок серий, настройки количества и локальное хранение с отдельным идентификатором `material`. Шахматные движки, доска, старые упражнения и их результаты не менялись. Новый тренажер не отображается в MathLab; повторно используется его техническая оболочка. SVG — существующие Merida, с относительным базовым путем приложения.

Проверки: `npm test -- --maxWorkers=2`, `node e2e/material.mjs`, `npm run test:math`, `npm run build`. Браузерные проверки Chromium с эмуляцией мыши/касания; физический iPad не проверялся.
