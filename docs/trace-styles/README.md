# Стили линии «Вектора»

В «Моторике → Векторе» рядом с кнопками запуска доступен селектор «Линия» / accessible name «Стиль линии»:

- Огненная: прежние оранжевое ядро, языки огня и искры сохранены.
- Ледяная: холодная светлая линия, ромбовидные кристаллы с гранями и мягким изменением прозрачности.
- Ветреная: светлые воздушные завитки и движущийся штриховой след, ориентированные вдоль движения.

Предпочтение хранится отдельно: `sciencechess-trace-style:v1:<profile>`. По умолчанию и при неизвестном значении используется огонь. Недоступный localStorage не мешает смене стиля в текущем упражнении. «Сигнал» и «Маршрут» не показывают этот селектор и очищают след при переходе.

`src/modules/motorics-trace-style.ts` содержит реестр, проверку сохраненного значения и геометрию. `motorics-trace-style.css` — изолированные правила для SVG data-style. Существующая огненная разметка и CSS не заменены. Один пул из 18 якорей переиспользуется для трех вариантов, узлы не создаются при движении. Новые украшения используют существующую ограниченную выборку `traceFireAnchors`; исходные samples, время, проверка попаданий и подсчет эффективности не меняются. Смена стиля перерисовывает те же samples; повтор не перезапускается. Слой сохраняет pointer-events:none. Новых JavaScript animation timers нет, prefers-reduced-motion отключает CSS-анимации.

Проверки:

- `npm test`: реестр и безопасный fallback, отдельная геометрия, прежние тесты ограниченности декоративной выборки и остальной проект.
- `node e2e/trace-styles.mjs`: все три стиля на 320×568, 390×844, 820×1180, 844×390, 1440×900; одинаковые координаты и текущий повтор при переключении, один результат после настоящего попадания, неизменный размер пула, сохранение, очистка и reduced motion.
- `node e2e/signal-touch.mjs`: нативные легкие касания, счет и звук в другом режиме «Моторики».
- `npm run build`: production TypeScript/Vite/PWA.

Скриншоты — `screenshots/`. Браузерная проверка — Chromium; физический iPad/Safari не проверялся.
