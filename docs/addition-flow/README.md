# Поток сложения

MathLab → Поток сложения, прямая ссылка `#math-addition-flow`.

- Режимы: «Бесконечный», «До первой ошибки» (1 жизнь) и «Три жизни» (3 сердечка). Неверный ответ убирает сердце, верный не расходует жизни. При нуле жизней ввод блокируется, показывается правильная сумма и результат; «Новая попытка» восстанавливает жизни. Короткая блокировка после ошибки защищает от двойного нажатия.
- Бесконечная последовательность сложений с положительными целыми слагаемыми, сумма до 10 по умолчанию или до 20.
- Выбор ответа кнопками 0–10 / 0–20 без текстового поля и экранной клавиатуры. Доступны обычные Tab/Enter/Space.
- Правильный ответ блокирует ввод на 350 мс, показывает подтверждение и автоматически открывает следующий пример. Неправильный оставляет текущий пример, правильный ответ заранее не раскрывается.
- При принятом ответе звучит короткий деревянный стук. Кнопка «Звук: вкл/выкл» использует общую настройку звуков сайта; выключение сохраняется. На автоматическом переходе и заблокированном вводе звука нет. Локальный обработчик ответа воспроизводит звук один раз, общий обработчик кнопок пропускает элементы с `data-action-sound="manual"`.
- Решено — число завершённых примеров; точность — доля примеров, решённых с первой попытки; ошибки — число неверных ответов. Ограничения времени нет; в режимах выживания попытка заканчивается при потере всех жизней. Точность включает текущий пример с ошибкой, даже если он пока не решён.
- Перемешанная колода из 25 или 100 разных пар заново перемешивается после исчерпания. Соседние пары не повторяются, включая перестановку слагаемых. Память не растёт с продолжительностью работы.
- Локальный снимок прогресса обновляется после каждого ответа: текущий пример, первая попытка, счётчики, диапазон, режим, оставшиеся жизни и завершение попытки. Старые снимки автоматически открываются в бесконечном режиме без потери прогресса. После перезагрузки можно продолжить. Изменение диапазона и «Начать заново» сбрасывают поток. При недоступном localStorage работает сохранение в памяти вкладки.
- Пространство хранения: `sciencechess-mathlab:v1:<profile>:addition-flow`, version 1. Старые математические и шахматные результаты не меняются.
- При уходе со страницы таймер очищается; следующий пример заранее сохранён, двойной ответ не засчитывается.

Код: `src/modules/mathlab/addition-flow.ts`; локальные стили — существующий `styles.css`. Пункт маршрутизации в `main.ts`, карточка в `mathlab/index.ts`. Без новых зависимостей и серверной части.

Проверки: `tests/addition-flow.test.ts`, `node e2e/addition-flow.mjs`, `node e2e/addition-sound.mjs`, `node e2e/move-sound.mjs`, `npm run test:math`, `npm run build`. Скриншоты `screenshots/{phone,tablet,desktop}.png`. Браузерная проверка — Chromium с эмуляцией касания, физические iPad/Safari не проверены.
