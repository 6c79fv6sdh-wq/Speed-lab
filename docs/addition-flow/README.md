# Поток сложения

MathLab → Поток сложения, прямая ссылка `#math-addition-flow`.

- Бесконечная последовательность сложений с положительными целыми слагаемыми, сумма до 10 по умолчанию или до 20.
- Выбор ответа кнопками 0–10 / 0–20 без текстового поля и экранной клавиатуры. Доступны обычные Tab/Enter/Space.
- Правильный ответ блокирует ввод на 350 мс, показывает подтверждение и автоматически открывает следующий пример. Неправильный оставляет текущий пример, правильный ответ заранее не раскрывается.
- Решено — число завершённых примеров; точность — доля примеров, решённых с первой попытки; ошибки — число неверных ответов. Таймера и конечной серии нет.
- Перемешанная колода из 25 или 100 разных пар заново перемешивается после исчерпания. Соседние пары не повторяются, включая перестановку слагаемых. Память не растёт с продолжительностью работы.
- Локальный снимок прогресса обновляется после каждого ответа: текущий пример, первая попытка, счётчики и диапазон. После перезагрузки можно продолжить. Изменение диапазона и «Начать заново» сбрасывают поток. При недоступном localStorage работает сохранение в памяти вкладки.
- Пространство хранения: `sciencechess-mathlab:v1:<profile>:addition-flow`, version 1. Старые математические и шахматные результаты не меняются.
- При уходе со страницы таймер очищается; следующий пример заранее сохранён, двойной ответ не засчитывается.

Код: `src/modules/mathlab/addition-flow.ts`; локальные стили — существующий `styles.css`. Пункт маршрутизации в `main.ts`, карточка в `mathlab/index.ts`. Без новых зависимостей и серверной части.

Проверки: `tests/addition-flow.test.ts`, `node e2e/addition-flow.mjs`, `npm run test:math`, `npm run build`. Скриншоты `screenshots/{phone,tablet,desktop}.png`. Браузерная проверка — Chromium с эмуляцией касания, физические iPad/Safari не проверены.
